## Introduction to Python
Python is a popular, general-purpose programming language released in **1991**.
It is known for its simple and readable syntax, which makes it easy for beginners to learn.

Python is widely used in:
- Data analysis and data science
- Machine learning and artificial intelligence
- Web development
- Automation and scripting

In data analytics, Python is popular because of libraries like **Pandas**, **NumPy**, **Matplotlib** and **Seaborn**.

## Features of Python
| Feature | Meaning |
|---|---|
| **High-level programming language** | Python is close to human language and easy to read and write. We don't need to manage memory or hardware details. |
| **Interpreted language** | Code is run line by line by the Python interpreter. There is no separate compile step. |
| **Dynamically typed** | We don't need to declare the data type of a variable. Python decides the type automatically at runtime (e.g. `x = 10` is an integer, `x = "hi"` is a string). |
| **Object-oriented** | Python supports classes and objects, so code can be organised into reusable objects. |
| **Functional programming** | Python supports functions as building blocks, and functions can be passed and returned like values (e.g. `map()`, `filter()`, `lambda`). |

## Technical Terms (Symbols)
| Symbol | Name | Common Use in Python |
|---|---|---|
| `{ }` | Curly braces | Dictionaries and sets |
| `( )` | Parentheses | Calling functions, tuples, grouping expressions |
| `[ ]` | Square brackets | Lists, indexing and slicing |
| `!` | Exclamation mark | Used in `!=` (not equal to) |
| `*` | Asterisk | Multiplication; `**` is power |
| `' '` | Single quotes | Writing strings |
| `" "` | Double quotes | Writing strings |

## Key Takeaway
Python is a simple, high-level, interpreted and dynamically typed language that supports both object-oriented and functional programming. Knowing the correct names and uses of symbols makes it easier to read code and follow instructions.
